# P03.01: versioned district network

`geometry_version: 2026-09-18.1`. Twelve intersections across three parallel
east-west corridors (A, B, C; four intersections each), connected by two
north-south cross-streets at the west (x=0) and east (x=900) columns. Every
intersection is traffic-light controlled. Built from plain-XML SUMO input
under `plain/` (hand-authored, versioned, reviewable) via `netconvert`.
Generated network/simulation output is gitignored (`output/`) and
regenerated by the build.

## Layout

```
int-c1 --- int-c2 --- int-c3 --- int-c4   corridor C
  |                                |
int-b1 --- int-b2 --- int-b3 --- int-b4   corridor B
  |                                |
int-a1 --- int-a2 --- int-a3 --- int-a4   corridor A
```

Corridor edges (`corridor` type): 2 general lanes plus a dedicated,
protected bicycle lane and a sidewalk (general lanes disallow
pedestrian/bicycle). Cross-street edges (`cross-street` type): 2 general
lanes plus a sidewalk, no dedicated bike lane.

## Reproduction

```bash
bash source-code/simulator/network/run_container.sh
```

Runs `build_and_verify.py` inside the digest-pinned
`ghcr.io/eclipse-sumo/sumo` image used by P01.06
(`docs/environment/SUMO_FEASIBILITY.md`). It:

1. Runs `netconvert` and asserts a clean `Success.` with zero warnings.
2. Asserts exactly 12 `tlLogic` (traffic-light) intersections and at least
   one generated pedestrian crossing.
3. Asserts every one of the 18 corridor edges isolates bicycle traffic onto
   exactly one dedicated lane, separate from general traffic.
4. Runs a small demo simulation (`demand/district-demo.rou.xml`): one car
   sanity-checks corridor connectivity, one cyclist proves the protected bike
   lane is usable end to end, one transit bus completes a scheduled route
   with two stops (`demand/stops.add.xml`) crossing from corridor A to
   corridor C.
5. Asserts zero teleports and zero collisions (network/signal validity), the
   bus completed both stops in order, and the cyclist's FCD trace never left
   the dedicated bike lane (`_1` lane index) or an internal junction lane.

Last verified run (2026-09-18): 12 traffic lights, 16 crossings, 18/18
corridor edges bicycle-isolated with zero violations, 3/3 vehicles
completed, zero teleports/collisions, bus stops completed in order
`[stop-crossing-bc, stop-corridor-c]`.

## Scope

This is the network and a minimal drivability demonstration only. Full
deterministic multi-mode demand (vehicles, pedestrians, cyclists, transit,
weather/road sensors at scale) is P03.02/P03.03. Emergency units and
CAD/AVL events are P03.04. Fault/scenario injection is P03.05/P03.06.
